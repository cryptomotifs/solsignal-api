BEFORE YOU INTEGRATE
Clear limits.
No surprises.
What payment methods are supported?
The paid tools use x402 v2 with USDC on Solana. There is no card checkout or self-service subscription here. You need a compatible payment client and your own wallet; this website never asks for a seed phrase.
What can these tools process?
Public URLs and repositories only. PDF extraction uses an existing text layer, not OCR. JavaScript-only pages may not yield useful text. Repository checks report public metadata and are not a security audit. See the API docs for size limits and request parameters.
Is this a trading product?
This storefront focuses on developer utilities. The API also exposes experimental market-data tools, which are research outputs, not guarantees of safety, returns, or investment advice. Nothing here trades for you.
Can I rely on it for critical workloads?
This is an early release on free hosting. Cold starts, upstream rate limits, and outages are possible; there is no uptime guarantee. Verify suitability with a small integration before using it in production. Do not submit confidential documents, credentials, or personal data.
